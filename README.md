# AI-article-summarizer
AI article summarizer 

# chrome extension article summarizer powered by google ai api

## how to use:
1. turn on Developer mode in chrome
2. click load unpacked and chose the folder that contains manifest.json
3. it will ask for your gemini key you can get one from google
4. click on the extension icon while on an article
5. choose a summary type from drop down menu
6. enjoy :)
